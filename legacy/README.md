# Legacy prototype

`prototype.html` is the original single-file Firebase + WebRTC proof of concept this repo started from. It is kept for reference only and is not part of the Bounce build — see `docs/PRD.md`, `docs/FSD.md`, and `docs/ROADMAP.md` for the current product and architecture, and the Next.js app at the repo root for the active codebase.

It relies on a hardcoded Firebase project config and has no moderation, matching filters, or safety features — do not deploy it.
